# 狀態與元件

| 情境 | 提供的訊息或行為 |
| --- | --- |
| 首次無資料 | 例如尚未建立專案，提供建立入口；尚無用途的篩選可等資料出現 |
| 搜尋無結果 | 保留查詢及篩選，讓使用者能修改或清除條件 |
| 詳情區 | 先依 [使用體驗入口](../SKILL.md) 判斷狀態，再決定何時呈現及如何連回選取操作 |
| Loading | 等待的對象；長流程說明可否離開，數字來自真實進度 |
| Success | 讓使用者看到對應對象、實際結果與可做的下一步 |
| Error | 問題與恢復方式；保留輸入，避免把系統故障怪到使用者 |
| Permission | 缺哪項存取與可走的請求路徑，不暴露不該知道的資源 |
| 危險操作 | 具體對象、後果；依不可逆性選確認或 undo |
| Form | 可見 labels、必要欄位、欄位旁錯誤與防重複提交 |
| CLI | 可發現的 help、穩定 exit code、清楚參數單位與結果 |
| Config | 清楚命名、常用預設、實際範例，缺必需值時明確失敗 |

文案例：「連線中斷，尚未儲存。輸入已保留，請重試。」
比「Something went wrong」更能操作；也不需解釋內部架構。

操作與導覽採原生語意；dialog/trap focus/返回焦點與 Escape 依互動模式處理。
