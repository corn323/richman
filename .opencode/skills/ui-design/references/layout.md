# 版面、分組與間距

## 寬度來自內容

長文需要能連續閱讀的行長，表單需要合適的輸入寬度，作品需要看清主體的尺寸，比較資料需要相鄰對齊。先確定這些區域如何一起工作，再決定外層容器；同一個 max-width 或等寬欄不是構圖答案。

寬螢幕可以保留外側空間，但主體不應像一塊孤島；也不要把主體硬拉寬到不利閱讀。看內容群與整個 viewport 的比例、重心與上下接續：留白是在聚焦、分節，還是未處理的剩餘空間？可以改各區域的相對位置與尺度，不只在全寬與置中窄欄之間二選一。導覽或表單可以有適合內容的固定寬度，主要工作區再彈性分配。

## 分組的形式

卡片、分隔線、底色與留白都是表達關係的手段，沒有一種天然比較成熟。可獨立選取、搬移或深入的物件，卡片能清楚表達範圍；密集資料容易看錯列時，細分隔線幫助追蹤；內容本來連續時，強行切斷反而增加重啟閱讀的負擔。

把卡片換成逐段橫線，若仍是相同的等權單元，只是換了表面符號，沒有完成資訊設計；反過來，拿掉線條或全部放回卡片也不會自動改善構圖。邊界妨礙觀看時，先改分組或空間，再決定需不需要框、線或底色。輸入欄位、焦點與互動狀態的可辨認性必須保留。

## 間距與密度

先做看得出差別的調整觀察關係，再收斂到現有 tokens；每次只改一點微小數值，容易維持原本失衡的比例。需要同時比較很多資料時，密度是合理取捨；檢查「更多資料同屏」是否真的減少往返與記憶，而不只是塞滿。

## 窄螢幕

重新安排閱讀順序與空間，保留需要的對照與單位，不把桌機的每個尺寸等比縮小。桌機有效的標題落差不必保留到手機；小字通常比大標更少縮。
