# 圖像、素材與深度

## 素材在這裡的工作

先確定素材是供辨識、作證據、展現空間或物件，還是建立情緒。看原檔的解析度、主體位置、視線、明暗、可裁切範圍與使用授權，再安排文字和操作。找到一張真圖放進標準比例的方框，不等於完成素材設計；`cover` 不是構圖決策。

- 圖像本身是使用者要看的內容時，保留足以觀看的尺寸和細節。完整 screenshot 過度縮小會失去證據；改用合適視窗的截圖或有意義的局部，不重建假畫面。
- 照片裁切到視覺中心不一定等於內容中心；窄螢幕另外取景。
- 例：修復工坊的前後照片是證據而不是 banner。讓同一部位以可比較的尺度與位置出現，文字在差異旁解釋；大標若把照片壓到看不清接合處，就沒有服務觀看目的。

## 圖與文字

圖上文字可讀只是必要條件。先試文字位置、局部對比處理、裁切或分開排；若 overlay 把作品的光線、色彩或細節消掉，構圖就不成立。高細節圖沒有足夠負空間時，把長文字移到閱讀表面，用位置、尺度和共同邊界連接。分開排之後仍要有比例與連結，不能變成互不相干的大標加圖片。

選擇性淡化或景深可以讓焦點更清楚，前提是先決定誰清楚、誰退後；它不能替整張白霧辯護。

## 深度

深度說明覆蓋與前後關係。浮層、被抬起的物件與平面資料不應都套同一種卡片陰影；沒有深度需求時，對齊、空間與表面即可。光源、邊界、icon 筆畫與文字重量需要協調。

## 素材不足與普通狀態

- 沒有圖片時，用真實內容、字體層級與空間形成構圖。可在授權內找或產生素材，保留可追溯來源；必要缺件清楚標示。不捏造 screenshot，也不以灰盒當作完成的主視覺。
- 空選取、缺資料或靜態提醒也屬於完成度：先確定當下資訊與操作，再決定形態，不用插畫、色線 panel 或鼓勵口號把空處補滿。
- 移除裝飾可以找出干擾，不能證明美術品質；素材誠實與能操作是必要條件，之後仍要判斷圖文比例、色彩關係與連續閱讀。
