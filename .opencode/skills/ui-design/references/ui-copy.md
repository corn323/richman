# 介面文字的例子與元件實作

規則只維護在 [SKILL.md 的介面文字](../SKILL.md#介面文字)。本頁補有條件的例子與元件做法，不另立一套規則。

- 「匯出紀錄」下面的「在這裡查看並管理你的匯出紀錄」沒有新增資訊，刪。失敗記錄旁的「連線中斷，檔案尚未產生。重試」改變下一步，保留。若匯出可能包含敏感欄位，選擇範圍時還需要明示，不能因錯誤訊息足夠就省略這項限制。
- 同一事實出現在不同決策位置未必是贅述：表單會滾出概要區時，送出前仍可能需要費用摘要。但同一個空選取區的角落標籤、大標與段落都只說「尚未選取」，就沒有增加資訊。不要把可能有用的其他情境當成保留當前重複的理由。
- 檢查共用元件的 eyebrow、subtitle、description 預設值、必填 props、預留高度與示範呼叫。沒有補文應是正常可用的狀態，不自動補字或留下空白間距。用一個不需說明的標題和一個確需限制提示的畫面驗證；標點 regex 無法判斷語義。
