# 字體與排版

用實際標題、資料、數字與正文試字。字面、粗細、行長、行高和周圍空間一起決定閱讀與性格；字級只是其中一項。品牌字體是起點，不是忽略缺字、過輕或不適合長文的理由。

## 選字

- 既有字體是起點，系統字型 stack 也是有效選項。換字體需要可見理由，例如字面比例、筆畫密度或長文表現；風格詞不能代替實際字樣。
- 讓字體與內容氣質協調，也看任務：高頻掃讀的工具未必適合全文手寫感；程式字串與需要對齊的數字另選合適字型。
- 以長中文標題、數字與正文一起看，而不是只讓英文 logo 有性格。

## 繁體中文與混排

- 注意缺字、標點擠壓、過細字重、語義斷行及中英字面差異。不要把英文的緊字距、全大寫或 italic 習慣移入中文。
- 標題跨行時觀察語義斷點與左右重量，而非只設一個巨大字級。
- 英文 45–75 字元的行長起點不能直接當作中文字數；行高與欄寬一起調，長文與短 UI label 不共用一個無條件的行高。
- 混合字級的同一行可先試基線對齊。數字比較需要穩定的小數位、單位與對齊；`tabular-nums` 是否有效要看實際字型。

## 層級與尺度

主資料與支持資料先各自達到舒適的閱讀尺度，再用字重、位置與對比形成層級。空間關係還沒成立前，不花時間比較難以看出差異的細小值；需要新尺度時先試足以改變關係的差異，再沿用或擴充少量 tokens。

## 載入

控制字集與 weight 的傳輸量；檢查 `font-display`、fallback 與載入前後的版面跳動，以及最終真的顯示哪個字型，而不只讀 `font-family` 宣告。
