# 動態互動模式

依實際問題選一種起點，不要求同時使用。

| 情境 | 行為與容易漏掉的事 |
| --- | --- |
| Press | pointer-down 立即回饋；放開還原；取消不提交 |
| Hover / focus | 提示可操作，不移動 hit target；focus ring 立即可見 |
| Toggle / tab | 狀態、指示器與焦點一致；快速切換取消舊效果 |
| Accordion | 內容開合與 expanded 語意同步，保持閱讀位置 |
| Success | 真實完成後才顯示結果，不提前演出付款或存檔成功 |
| Error | 保留輸入，文字指出受影響處與恢復方式；shake 可選 |
| Loading | 進度來自資料；不可量化時不用虛構百分比 |
| 進退場 | 有來源就保留空間關係；普通狀態替換可短淡入或直接切換 |
| 列表 / grid | 依閱讀順序或資料關係錯開；大量項目限制總等待 |
| Drag/drop | 指標連續追蹤，其他項目讓空間，drop/cancel 後穩定 |
| 環境循環 | 只有 brief 支持才加入，提供適當暫停，reduced motion 靜態 |

選屬性：位置表達來源去處，scale 表達按壓或遠近，opacity/顏色表達狀態；重要訊息同時有文字或語意。opacity-only 合法，沒有必要就不加位移。

多元素編排先讓人看懂重要內容，不用固定「同時最多 1/3」或強制共同方向。modal 關閉與必要控制從開始即可用，不能為編排最後才出現。

同一事件觸發的元素可一起動；獨立訊息可 stagger。共享元素進退場避免閃爍；快速中斷接續目前值。

品牌場景可有反向背景、速差或小幅呼吸，不是功能 UI 預設。循環無接縫、離開頁面停止，文字和主操作穩定；不能宣稱固定元素數以下必然流暢。
