# 程式修改

依 agent-kit 的 `core/CORE_RULES.md` 唯讀定位相關程式與依賴，只在已授權目標內修改。範圍外修復需求依共同邊界處理；不為每次讀檔重新詢問。

- 修 bug：沿症狀追資料流與相關呼叫端，在授權範圍內修正共同原因。
- 需求不明：只有會改變結果的歧義才提出；可逆細節沿用專案慣例，說明必要假設後繼續。
- 放置程式：靠近相同職責的模組。入口、index 與 aggregator 保持組裝用途；不要為省一個檔案塞入新職責。
- 優先重用既有函式、標準函式庫與依賴。不要新增只有一種用途的抽象或未要求的設定。
- 驗證決策沿用 agent-kit 的 `core/WORKFLOWS.md`。

報告實際改變、驗證結果與未證明的部分。部署、啟動與真實使用者流程各是不同證據。
