# 素材一致性

只有本次需要的素材才列入既有 manifest 或一份簡短清單：stable key、用途、來源／檔案、比例與 anchor。沿用專案格式，不強制另造 CSV。

風格描述固定媒材、線條、色彩角色、光感、視角；每張圖的主題、尺寸與透明背景另外寫。這讓不同物件共用風格，又不把整套素材都壓成同色同亮度。

- SVG／程序圖形適合簡單線條、可編輯形狀與已有向量系統。繪畫質感或 bitmap 素材才使用可用的 image generation 流程。
- 生圖採工作環境可用且已授權的工具。是否有 alpha、模型名稱、尺寸限制依工具當前能力；不要沿用上游「模型都不能產透明圖」之類的固定假設。
- 僅在工具不支援 alpha 且確實需要去背時，選不在角色色盤內的底色。不能留下假棋盤格；檢查物件內部孔洞、邊緣與陰影。
- Sprite sheet 確認每格尺寸、anchor、視角和物件尺度；需要動畫時先保住角色輪廓，再產生整段動作，避免逐格各自生成導致漂移。
- 背景保留可操作物件的位置與對比。不要把 UI、角色或尚未建造的設施烘進背景。
- 以實際遊玩尺度把素材放在一起看：剪影、線條粗細、光向、視角、相對大小、輪廓與背景分離是否一致。孤立大圖的精緻度不算驗收。
- 有局部漂移就改那個素材。整套風格只有在使用者要求改方向時才重新決定；保留可回復的舊版，不清除非本次產生的檔案。
